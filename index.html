🏠 Property Risk Manager

Track properties, tenants, payment risk, and automated alerts on at-risk accounts.

This is a portfolio demo. All data (properties, tenants, communication notes) is fictional sample data, seeded on first load. Everything is editable — add/edit/delete properties, update tenant payment status, log communications, and run the risk calculators. Edits save to your browser only (localStorage); nothing is ever sent to a server. Use Reset in the toolbar to restore the original demo data.
